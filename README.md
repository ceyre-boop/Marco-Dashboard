# Marco's Data Dashboard

A premium, high-stakes CEO command center for agency management, built from Stitch designs.

## Features
- **CEO Command Center**: Agency-wide pulse and growth velocity.
- **TikTok Shop Analytics**: Deep dive into shop momentum and creator earnings.
- **TikTok LIVE Analytics**: Global live volume and streamer efficiency.
- **Creator Intelligence**: A-List status tracker and creator roster health.
- **GPT-5 Command Center**: AI-powered reporting and integration tools.

## Design
Rooted in "The Pulse of Influence" narrative:
- Atmospheric midnight spectrum palette.
- Glassmorphic components.
- Editorial-grade typography (Manrope & Inter).

## Tech Stack
- HTML5
- Tailwind CSS (via CDN)
- Google Fonts & Material Symbols
